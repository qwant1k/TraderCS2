# TradeGG Helper (Chrome / Edge / Brave)

Расширение подставляет предметы в окно обмена Steam из принятого предложения TradeGG и проверяет итоговый список.

Перед упаковкой выполните `npm run extension:build`. Скрипт возьмёт `APP_URL` из `.env`
и ограничит content script именно этим origin; широкого доступа ко всем сайтам расширение не запрашивает.

## Установка (режим разработчика)

1. Откройте `chrome://extensions` (в Edge `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» и выберите папку `extension`.

## Как работает

1. На TradeGG владелец лота нажимает «Принять», затем «Открыть трейд в Steam». Страница TradeGG передаёт расширению план обмена (кто партнёр, какие предметы с каждой стороны).
2. На странице обмена Steam расширение само отмечает нужные предметы и показывает плашку сверху.
3. Плашка зелёная, если в окне ровно те предметы, что были в предложении. Красная, если появились лишние предметы. Проверка идёт постоянно, пока вы на странице.
4. Расширение никогда не нажимает «Готово» и не подтверждает обмен. Это делаете вы, и в Steam всегда стоит сверить партнёра и предметы.

План записывает только страница TradeGG, поэтому подделать его ссылкой на Steam нельзя. План живёт 30 минут и действует только для партнёра из этой ссылки.

## Свой домен

Задайте домен в `APP_URL`, выполните `npm run extension:build` и обновите расширение на странице
`chrome://extensions`. Скрипт заменит localhost только на этот origin.

## Ограничения

- Разметка страницы обмена Steam не документирована и может измениться. Код опирается на известные идентификаторы элементов (`your_slots`, `their_slots`, `item<app>_<context>_<assetid>`), проверен на макете такой страницы, но не на живом Steam. Если подстановка не срабатывает, отметьте предметы вручную: проверка списка продолжит работать.
- Проверяются только предметы CS2 из плана.
