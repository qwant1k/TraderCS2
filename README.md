# TradeGG — обмен скинами CS2 напрямую между игроками

TradeGG — площадка для поиска и организации обменов предметами Counter-Strike 2 между игроками Steam. Пользователь подключает свой Steam-профиль, выбирает скины из инвентаря, публикует лот и указывает, что хотел бы получить взамен. Другие участники могут предложить собственные предметы, а после принятия предложения обе стороны завершают обмен в официальном интерфейсе Steam.

Сервис не выкупает предметы, не хранит их на внутреннем балансе и не проводит денежные расчёты. TradeGG помогает сторонам найти друг друга, сравнить предметы и согласовать состав обмена, сохраняя окончательное решение за владельцами инвентарей.

> Текущая версия проекта — MVP. Основной пользовательский сценарий уже реализован, но перед публичным коммерческим запуском проекту потребуются дополнительная нагрузочная проверка, модерация и юридическая подготовка.

## Идея проекта

Обычные торговые площадки ориентированы на покупку и продажу скинов. TradeGG решает другую задачу: помогает обменять уже имеющиеся предметы на те, которые действительно нужны пользователю.

Площадка подходит игрокам, которые:

- хотят обновить инвентарь без продажи предметов и последующей покупки новых;
- коллекционируют определённые скины, флоаты, паттерны или наклейки;
- готовы рассматривать разные варианты равноценного обмена;
- хотят заранее сравнить рыночные ориентиры и характеристики предметов;
- предпочитают подтверждать сделку самостоятельно через Steam.

## Как проходит обмен

1. **Вход через Steam.** Пользователь авторизуется с помощью Steam OpenID. TradeGG получает публичный идентификатор профиля, но не видит и не хранит пароль Steam.
2. **Настройка профиля.** Пользователь добавляет свою трейд-ссылку, при желании указывает почту, Discord, Telegram и краткую информацию о себе.
3. **Загрузка инвентаря.** Сервис получает доступные для обмена предметы из публичного инвентаря CS2 и показывает их характеристики, изображения и ценовые ориентиры.
4. **Создание лота.** Один или несколько предметов переносятся в блок «Ожидают предложений». Для лота можно разрешить любые предложения или указать до пяти подходящих вариантов обмена.
5. **Поиск второй стороны.** Другие игроки находят лот в общем каталоге либо через систему совпадений, которая сопоставляет предметы и пожелания участников.
6. **Обсуждение через предложения.** Заинтересованный пользователь выбирает предметы из своего инвентаря и отправляет владельцу лота конкретное предложение.
7. **Проверка и принятие.** Владелец сравнивает предметы, цены, float и другие параметры. При принятии TradeGG повторно проверяет наличие предметов и резервирует лот от повторного принятия другого предложения.
8. **Завершение в Steam.** Сервис открывает страницу обмена Steam и показывает согласованный состав сделки. Каждая сторона самостоятельно проверяет и подтверждает обмен в Steam.

## Основные возможности

### Инвентарь и карточки предметов

- загрузка инвентаря CS2 с кэшированием для снижения числа запросов к Steam;
- поиск, фильтрация и сортировка предметов;
- отображение редкости, качества, StatTrak™, наклеек, float и pattern seed;
- ориентировочные цены Steam Community Market и Skinport;
- шкала износа и быстрый переход к осмотру предмета в игре;
- отдельная подробная карточка предмета;
- интерактивный 3D-просмотр экземпляра по inspect-ссылке, включая наклейки, charm и StatTrak™;
- информация о предложении и спросе на аналогичный предмет внутри TradeGG.

### Лоты и пожелания

- публикация одного или нескольких предметов в составе лота;
- режим «Открыт для предложений» для свободного обмена;
- режим «Хочу конкретное» с несколькими допустимыми вариантами;
- локальный каталог скинов CS2 с автодополнением по названию;
- просмотр активных лотов всех участников;
- отзыв собственного лота до завершения обмена.

### Предложения и подбор пар

- создание предложения из предметов собственного инвентаря;
- привязка предложения к конкретному пожеланию владельца лота;
- принятие, отклонение и отзыв предложения;
- защита от одновременного принятия нескольких предложений на один лот;
- автоматический подбор трёх типов совпадений: взаимные пары, предметы, которые пользователь может предложить, и лоты с тем, что он ищет;
- повторная проверка инвентарей перед переходом к обмену.

### Профиль и доверие

- публичная страница участника с аватаром, статистикой и активными лотами;
- редактируемое описание и дополнительные способы связи;
- подтверждение адреса электронной почты;
- проверка принадлежности Steam trade URL текущему пользователю;
- уровни доверия от 0 до 3;
- лимиты на число активных лотов и предложений в зависимости от уровня;
- учёт только тех завершённых сделок, которые подтвердили обе стороны.

### TradeGG Helper

В каталоге `extension/` находится расширение для Chrome, Edge и Brave. Оно помогает перенести согласованный состав сделки в окно Steam и сверяет предметы перед подтверждением. Расширение не подтверждает обмен вместо пользователя: окончательная проверка и отправка всегда выполняются вручную в Steam.

## Безопасность и контроль пользователя

- TradeGG использует Steam OpenID и никогда не запрашивает пароль от Steam.
- Предметы остаются в инвентарях владельцев до момента подтверждения обмена.
- У сайта нет собственного кошелька, баланса или хранения скинов.
- Принятый состав сделки повторно сверяется с актуальными инвентарями.
- Секреты приложения хранятся в локальном `.env`, который исключён из Git.
- Пользователь должен самостоятельно проверить предметы и получателя в официальном окне Steam.

TradeGG является независимым проектом и не аффилирован с Valve Corporation или Steam. Названия и товарные знаки принадлежат их владельцам.

## Что уже работает в MVP

- Вход через Steam OpenID (пароль Steam сайт не видит).
- Тёмный неоновый интерфейс, главная со статистикой.
- Публичный профиль `/u/<SteamID64>`: уровень доверия, статистика, активные лоты, соцсети.
- Настройки: трейд-ссылка (проверяется, что она ваша), почта, Discord, Telegram, «о себе».
- Уровни доверия 0–3: учитываются только сделки, завершение которых подтвердили обе стороны.
- Инвентарь CS2 с кэшем на 5 минут: цены (Steam Market, Skinport), флоат и паттерн (читаются из inspect-ссылки), наклейки, StatTrak™, фильтры и сортировка.
- Клик по предмету открывает карточку справа: шкала флоата, цены на площадках, «Осмотреть в игре», «В отдельном окне».
- Поле «Ожидают предложений»: сюда попадают предметы, добавленные в обмен, и отсюда лот публикуется.
- Несколько вариантов «что хочу» для одного лота (до 5): подойдёт любой. В предложении можно указать, на какой вариант оно отвечает.
- Локальный каталог всех скинов CS2 с изображениями, редкостью, оружием и float-диапазоном; пожелания ищутся с автодополнением без внешнего запроса на каждое нажатие.
- Лоты двух типов: «открыт для предложений» и «хочу конкретное».
- Предложения на лот, отзыв, отклонение; принятие атомарно резервирует лот и исключает второе принятое предложение.
- «Принять»: сайт заново проверяет инвентари обеих сторон и открывает панель с кнопкой на страницу Steam-трейда партнёра и списком предметов.
- Точный интерактивный 3D-просмотр экземпляра по inspect-ссылке: float, seed, наклейки, charm и StatTrak; режим в руках, освещение карт, fullscreen и безопасный fallback.

- Расширение браузера `extension/` (Chrome / Edge / Brave): подставляет предметы в окно Steam и проверяет, что трейд не изменили. Установка в `extension/README.md`.

Чего ещё нет (следующие этапы): уведомления (почта и Telegram), подтверждение соцсетей через вход, жалобы и отзывы, цены DMarket / CS.MONEY / Lis-Skins, другие игры.

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env     # на Windows: copy .env.example .env
# в .env задайте SESSION_SECRET (32+ случайных символов)
npm run db:migrate
npm run db:backfill      # безопасно повторяется; переносит старые JSON-предметы в индексы
npm run catalog:sync     # загружает полный актуальный каталог скинов CS2 в локальную БД
npm run dev
```

Откройте http://localhost:3000. Вход через Steam с localhost работает, если `APP_URL` в `.env` равен `http://localhost:3000`.

## Структура

- `prisma/schema.prisma` и `prisma/migrations/` — SQLite-схема и воспроизводимые миграции.
- `lib/steam.ts` — OpenID, профиль, инвентарь, проверка трейд-ссылки.
- `lib/parse.ts`, `lib/inspect.ts`, `lib/wear.ts` — разбор инвентаря, чтение флоата из inspect-ссылки, границы износа.
- `lib/prices.ts` — цены с кэшем 30 минут.
- `scripts/sync-skin-catalog.mjs` и `app/api/catalog` — синхронизация и локальный поиск по каталогу скинов.
- `app/api/*` — авторизация, инвентарь, профиль, лоты, предложения.
- `lib/trust.ts` — уровни доверия и лимиты.
- `app/*` и `components/*` — страницы и компоненты.
- `extension/` — расширение браузера.

## Обновление старой БД без истории миграций

Если база была создана старой командой `prisma db push`, сначала отметьте baseline, затем примените новую миграцию:

```bash
npx prisma migrate resolve --applied 20261011000100_baseline
npm run db:migrate
npm run db:backfill
```

Для новой пустой базы достаточно `npm run db:migrate`. Перед упаковкой расширения выполните
`npm run extension:build`: разрешённый origin будет взят из `APP_URL`.

## Важно знать

- Флоат читается из новых inspect-ссылок CS2 без ботов. Если Steam отдаёт старую ссылку или в ссылке нет данных об износе, флоат не показывается (можно подключить свой сервис осмотра через `FLOAT_API_URL`).
- Приватный инвентарь Steam прочитать нельзя: пользователь должен открыть его в настройках приватности.
- Steam ограничивает частоту запросов (ошибка 429). Для нагрузки нужен кэш в Redis и очередь.
- `SCREENSHOT_API_URL` должен быть HTTPS-шаблоном, возвращающим изображение и содержащим `{inspect}`.
- Текущие миграции предназначены для SQLite. Переход на PostgreSQL требует отдельной миграции и новой истории миграций, а не простой замены `provider`.
- Каталог скинов синхронизируется из MIT-лицензированного проекта ByMykel/CSGO-API, который извлекает данные из файлов CS2. Повторяйте `npm run catalog:sync` после крупных обновлений игры.
- Сайт сам не отправляет трейды от имени пользователя: он открывает страницу Steam, подтверждает пользователь.
- Перед публичным запуском проверьте условия Steam и сторонних API цен, а также юридические требования вашей страны.
