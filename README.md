# TradeGG — MVP

Обмен предметов Steam (CS2) между игроками без купли-продажи.

## Что уже работает

- Вход через Steam OpenID (пароль Steam сайт не видит).
- Тёмный неоновый интерфейс, главная со статистикой.
- Публичный профиль `/u/<SteamID64>`: уровень доверия, статистика, активные лоты, соцсети.
- Настройки: трейд-ссылка (проверяется, что она ваша), почта, Discord, Telegram, «о себе».
- Уровни доверия 0–3: учитываются только сделки, завершение которых подтвердили обе стороны.
- Инвентарь CS2 с кэшем на 5 минут: цены (Steam Market, Skinport), флоат и паттерн (читаются из inspect-ссылки), наклейки, StatTrak™, фильтры и сортировка.
- Клик по предмету открывает карточку справа: шкала флоата, цены на площадках, «Осмотреть в игре», «В отдельном окне».
- Поле «Ожидают предложений»: сюда попадают предметы, добавленные в обмен, и отсюда лот публикуется.
- Несколько вариантов «что хочу» для одного лота (до 5): подойдёт любой. В предложении можно указать, на какой вариант оно отвечает.
- Локальный каталог всех скинов CS2 с изображениями, редкостью, оружием и float-диапазоном; пожелания ищутся с автодополнением без внешнего запроса на каждое нажатие.
- Лоты двух типов: «открыт для предложений» и «хочу конкретное».
- Предложения на лот, отзыв, отклонение; принятие атомарно резервирует лот и исключает второе принятое предложение.
- «Принять»: сайт заново проверяет инвентари обеих сторон и открывает панель с кнопкой на страницу Steam-трейда партнёра и списком предметов.
- Точный интерактивный 3D-просмотр экземпляра по inspect-ссылке: float, seed, наклейки, charm и StatTrak; режим в руках, освещение карт, fullscreen и безопасный fallback.

- Расширение браузера `extension/` (Chrome / Edge / Brave): подставляет предметы в окно Steam и проверяет, что трейд не изменили. Установка в `extension/README.md`.

Чего ещё нет (следующие этапы): уведомления (почта и Telegram), подтверждение соцсетей через вход, жалобы и отзывы, цены DMarket / CS.MONEY / Lis-Skins, другие игры.

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env     # на Windows: copy .env.example .env
# в .env задайте SESSION_SECRET (32+ случайных символов)
npm run db:migrate
npm run db:backfill      # безопасно повторяется; переносит старые JSON-предметы в индексы
npm run catalog:sync     # загружает полный актуальный каталог скинов CS2 в локальную БД
npm run dev
```

Откройте http://localhost:3000. Вход через Steam с localhost работает, если `APP_URL` в `.env` равен `http://localhost:3000`.

## Структура

- `prisma/schema.prisma` и `prisma/migrations/` — SQLite-схема и воспроизводимые миграции.
- `lib/steam.ts` — OpenID, профиль, инвентарь, проверка трейд-ссылки.
- `lib/parse.ts`, `lib/inspect.ts`, `lib/wear.ts` — разбор инвентаря, чтение флоата из inspect-ссылки, границы износа.
- `lib/prices.ts` — цены с кэшем 30 минут.
- `scripts/sync-skin-catalog.mjs` и `app/api/catalog` — синхронизация и локальный поиск по каталогу скинов.
- `app/api/*` — авторизация, инвентарь, профиль, лоты, предложения.
- `lib/trust.ts` — уровни доверия и лимиты.
- `app/*` и `components/*` — страницы и компоненты.
- `extension/` — расширение браузера.

## Обновление старой БД без истории миграций

Если база была создана старой командой `prisma db push`, сначала отметьте baseline, затем примените новую миграцию:

```bash
npx prisma migrate resolve --applied 20261011000100_baseline
npm run db:migrate
npm run db:backfill
```

Для новой пустой базы достаточно `npm run db:migrate`. Перед упаковкой расширения выполните
`npm run extension:build`: разрешённый origin будет взят из `APP_URL`.

## Важно знать

- Флоат читается из новых inspect-ссылок CS2 без ботов. Если Steam отдаёт старую ссылку или в ссылке нет данных об износе, флоат не показывается (можно подключить свой сервис осмотра через `FLOAT_API_URL`).
- Приватный инвентарь Steam прочитать нельзя: пользователь должен открыть его в настройках приватности.
- Steam ограничивает частоту запросов (ошибка 429). Для нагрузки нужен кэш в Redis и очередь.
- `SCREENSHOT_API_URL` должен быть HTTPS-шаблоном, возвращающим изображение и содержащим `{inspect}`.
- Текущие миграции предназначены для SQLite. Переход на PostgreSQL требует отдельной миграции и новой истории миграций, а не простой замены `provider`.
- Каталог скинов синхронизируется из MIT-лицензированного проекта ByMykel/CSGO-API, который извлекает данные из файлов CS2. Повторяйте `npm run catalog:sync` после крупных обновлений игры.
- Сайт сам не отправляет трейды от имени пользователя: он открывает страницу Steam, подтверждает пользователь.
- Перед публичным запуском проверьте условия Steam и сторонних API цен, а также юридические требования вашей страны.
